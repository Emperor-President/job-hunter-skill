# Job Hunter Skill - 交互式求职辅导

一个帮助用户完成完整求职流程的AI技能，通过逐步引导帮助用户找到理想工作。

## 功能特性

- **自我分析**：帮助用户挖掘自身能力和价值
- **行业筛选**：基于实时数据筛选有前景的行业
- **公司定位**：找到值得投递的目标公司
- **岗位拆解**：将JD翻译为"麻烦语言"，理解真实需求
- **简历匹配**：针对目标岗位优化简历
- **面试准备**：模拟面试和案例准备

## 触发场景

当用户提到以下关键词时触发：
- 找工作、求职
- 简历、面试
- 选行业、选公司
- 岗位分析

## 核心原则

> 工作 = 有人有麻烦 + 愿意付钱 + 你能解决

## 使用方法

1. 将 `job-hunter.zip` 导入到支持skills的AI平台
2. 向AI描述你的求职需求
3. 按照引导逐步完成各个阶段

## 文件结构

```
job-hunter/
├── SKILL.md              # 技能定义和工作流程
└── references/
    ├── industry-guide.md # 行业筛选指南
    └── resume-guide.md   # 简历修改指南
```

## 交互流程

1. **自我分析** → 2. **行业筛选** → 3. **公司定位** → 4. **岗位拆解** → 5. **简历匹配** → 6. **面试准备**
